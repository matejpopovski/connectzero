tromp_8ply_sample.csv is a random sample of 60 rows from the Connect-4 opening database:
Tromp, J. (1995). Connect-4 [Dataset]. UCI Machine Learning Repository.
https://doi.org/10.24432/C59P43, licensed under CC BY 4.0.

The cell columns are joined into one string and the outcome is unchanged. Regenerate it with
scripts/validate_tromp.py and --sample-out.
